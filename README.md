# Pioneer Delivery Company Algorithm Portfolio

This repository contains my algorithm implementations for the Pioneer Delivery Company project. The portfolio is divided into three parts, with each part focusing on a different algorithm design technique.

## Github:

https://github.com/jadecodelab/pioneer-delivery

## Project Parts

### Part I: Greedy Algorithms

Part I uses greedy algorithms to solve delivery scheduling problems, including:

- Selecting compatible deliveries
- Determining the minimum number of drivers
- Assigning deliveries to drivers

See the [Part I README](part1/README.md) for details about the algorithms, input format, commands, and tests.

### Part II: Divide and Conquer

Part II uses divide-and-conquer algorithms to solve problems including:

- Finding the closest pair of points
- Counting dispatch inversions
- Finding a delivery time threshold

See the [Part II README](part2/README.md) for details about the implementations and test results.

### Part III: Dynamic Programming

Part III uses dynamic programming to solve:

- Maximum-profit delivery scheduling
- Delivery selection with a fuel budget
- Event-log cleanup while preserving a required sequence

See the [Part III README](part3/README.md) for details about the algorithms, testing, and documentation.

## Programming Language

The project was implemented in:

- Python 3

The algorithms use Python's standard library. No external packages are required.
